# Innehållskanon

- Huvudtes: samverkan ska prövas som ett **alternativ**, aldrig som självändamål.
- Tre ansvarsnivåer hålls isär: utveckling, styrning/finansiering, drift.
- Varje samverkansmodell måste innehålla **när lämplig / när olämplig**.
- Återkommande hypotetiskt exempel: regelmotor, tre eller fem myndigheter.
- Sakuppgifter och fallstudier tillskrivs verifierade källor; ekonomiexempel markeras hypotetiska.
- Respekt för svenska myndigheters separata ansvar och mandat.
- Svenska termer; förklara begrepp som värdmyndighet, anslagsfinansiering, öppen källkod, offentlig samverkan och livscykelkostnad vid första användning.
